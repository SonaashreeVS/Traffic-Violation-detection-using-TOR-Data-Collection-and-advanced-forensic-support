👾 Technolgies used 
Python 3.8+ - Core programming language
Flask - Web framework for REST API
Flask-CORS - Cross-origin resource sharing
SQLite - Lightweight database for violation storage
OpenCV - Image processing and computer vision
YOLOv8 (Ultralytics) - Real-time object detection
TensorFlow/Keras - Deep learning models
PyTesseract - OCR for license plate recognition
Haar Cascades - License plate detection
NumPy - Numerical computations
Pillow (PIL) - Image manipulation
Matplotlib - Visualization and plotting


🍀Functions: 
The application can be used in live detection of speedy and robust vehicles ensuring that no vehicles is left unchecked. 
It checks for multiple traffic violations like Helmet, line crossing, Red light crossing and more!
